# Swiss: `/design style swiss`

I make the typographic grid do the work. Alignment, scale and spacing set the hierarchy with little ornament.

---

## Required companion reference

I follow the [style workflow](style.md) for report context, scope, implementation and verification. The command loads it alongside this guide.

---

## The design pass

- I use one neutral grotesk or Helvetica-family sans with two or three weights. Headline scale, not extra fonts, creates the contrast.
- I align headings, metadata, images and body text to shared edges on a modular grid. Asymmetry is deliberate and the reading order stays clear.
- I structure the page with 1px hairline rules at low contrast. I avoid shadows, gradients and decorative card wrappers.
- I use one accent color, and only for actions and the current state.
- I start body text at 16 to 18px with a 55 to 75 character measure, aligned left.
- I collapse columns in DOM order on mobile and test 200% zoom. Visible focus, labels and empty states still apply.
